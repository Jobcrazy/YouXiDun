# NetGuard

[中文](./README.md)

NetGuard is a privately deployed game-network protection solution designed for high-concurrency, adversarial, and latency-sensitive environments. It builds a stable and reliable security perimeter for game servers and can be deployed on customer-owned servers or designated data-center nodes, keeping the protection path and data under the customer's control.

NetGuard provides unlimited defense capacity against large-scale UDP and TCP flood attacks while keeping game services available under intense attack traffic. Its zero-false-blocking strategy uses granular traffic identification and behavior analysis to filter malicious traffic while preserving access for legitimate players.

The core source code is maintained by the NetGuard engineering team. The solution supports self-hosted protection nodes, flexible expansion based on business scale, and SDK integration across Windows, Android, and iOS applications and games.

With source-level maintenance and rapid incident response, NetGuard supports DDoS mitigation, CC attack mitigation, and traffic encryption, giving game developers a controllable, stable, and continuously evolving protection platform.
